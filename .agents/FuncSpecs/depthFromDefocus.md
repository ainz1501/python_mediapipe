# depthFromDefocus 関数
焦点設定の異なる複数枚の画像（焦点スタック）をもとに、各画素の深度をまとめた深度マップと、全画素が合焦しているAIF画像を作成する。

配置ファイル名: depthFromDefocus.py
使用言語: python

## 使用外部ライブラリ・モジュール
- NumPy: ランドマーク、カメラパラメータ、回転行列、並進ベクトルの表現に使用する
    - 呼び出し方: `import NumPy as np`

## 使用独自クラス
- クラス名: FocalStack
焦点スタックに含まれる異なる光学パラメータの値で撮影した各画像の画素値と撮影時の各光学パラメータ（焦点距離、物体側の合焦距離、レンズ開口径、ピクセルサイズ）をまとめたクラス

## 引数
|引数名|型|shape|要素の型|説明|
|---|---|---|---|---|
|focalStack|dfd.FocalStack|-|-|焦点スタックに含まれる複数枚の画像と光学パラメータ|

## ハイパーパラメータ
記述箇所: depthFromDefocus.py

|パラメータ名|型|デフォルト値|説明|
|---|---|---|---|
|目標MSE値|float|0.01|反復の終了条件として使用する平均二乗誤差距離|
|エポック数|int|40|反復回数の上限|
|想定最小深度|float|0.1|写っている物体がカメラから見てどの深度にありうるかの最小値|
|想定最大深度|float|10.0|写っている物体がカメラから見てどの深度にありうるかの最大値|
|深度サンプリング数|int|100|深度範囲の中から等間隔に取得するサンプリングの数|
|黄金分割探索の最大反復回数|int|100|黄金分割探索の反復回数の上限。本誌では100回|
|黄金分割探索の許容誤差|float|0.01|黄金分割探索の許容誤差。本誌では $10^{-2}$ |
|べき乗法の反復回数|int|100|FISTAで使用するべき乗法の反復回数。今回は100回と設定|
|FISTAの初期反復回数|int|200|FISTAの反復回数の初期値。この反復回数終了時にも目的のMSEを満たさない場合は、[FISTAの反復回数増加倍率]をかけて再度その回数反復する。|
|FISTAの反復回数増加倍率|float|1.05|初期反復回数終了後にかける増加倍率。（1以上の値）|

## 戻り値
|戻り値名|型|shape|要素の型|説明|
|---|---|---|---|---|
|深度マップ|np.array|(H, W)|float|各シーンの画素におけるカメラ中心（レンズ）からの深度情報|
|AIF画像|np.array|(HW,C)|float|シーンの点全てのピントが合っている状態の画像|

## 処理フロー
- `initAIFImage`を呼び出し、焦点スタックから初期AIF画像を作成する
- `alternatingMinimization`を呼び出し、初期AIF画像をもとに深度マップとAIF画像を交互に最適化する
- 深度マップとAIF画像を返す

## 使用関数の呼び出し

### `initAIFImage`
記述ファイル名: `depthFromDefocus.py`

#### 入力

|引数名|型|shape|要素の型|説明|
|---|---|---|---|---|
|focalStack|dfd.FocalStack|-|-|焦点スタックに含まれる複数枚の画像と光学パラメータ|

#### 出力

|戻り値名|型|shape|要素の型|説明|
|---|---|---|---|---|
|initialAIFImage|np.array|(HW,C)|float|焦点スタックの画像から作成した初期AIF画像|

```python
initialAIFImage = initAIFImage(focalStack)
```

初期AIF画像を返す。

### `alternatingMinimization`
記述ファイル名: `depthFromDefocus.py`

#### 入力

|引数名|型|shape|要素の型|説明|
|---|---|---|---|---|
|initialAIFImage|np.array|(HW,C)|float|`initAIFImage`により作成したAIF画像|
|focalStack|dfd.FocalStack|-|-|焦点スタックに含まれる複数枚の画像と光学パラメータ|

#### 出力

|戻り値名|型|shape|要素の型|説明|
|---|---|---|---|---|
|depthMap|np.array|(H, W)|float|各シーンの画素におけるカメラ中心（レンズ）からの深度情報|
|AIFImage|np.array|(HW,C)|float|交互最小化により更新したAIF画像|

```python
depthMap, AIFImage = alternatingMinimization(initialAIFImage, focalStack)

```

戻り値は、深度マップ、AIF画像の順に返す。
反復の終了条件、グリッドサーチ、黄金分割探索、FISTAで使用するパラメータは`depthFromDefocus.py`内で設定し、引数には含めない。

## 前提条件・例外
- 焦点スタックに含まれる各画像、AIF画像は全て同じサイズ、同チャネル数
- 各画素の値は0~255までのいずれかの非負値である
- 焦点距離、各画像の合焦距離、レンズ開口径、ピクセルサイズは0より大きい
- 焦点スタックの画像枚数と合焦距離の要素数は一致する
- 数値条件に違反した`FocalStack`が入力された場合は`ValueError`を送出する

## テスト方法

### 個別テスト

- `initAIFImage`の仮置きが2次元の`np.ndarray`を返すことを確認する。
- `alternatingMinimization`の仮置きが、2次元の深度マップと2次元のAIF画像を`np.ndarray`として返すことを確認する。
- 各関数が返す配列が空でないことを確認する。

### 統合テスト

- テスト用のモック関数への置き換えは行わない。
- 数値条件を満たす既知の`FocalStack`を`depthFromDefocus`へ入力する。
- 実際の`depthFromDefocus`が返した深度マップとAIF画像を期待出力と直接比較する。
- 最終戻り値が深度マップ、AIF画像の順であることを確認する。
- 入力および期待出力には空配列を使用しない。

### テストデータ

- 初期AIF画像とAIF画像にはshapeが`(4, 3)`の行列を使用する。
- 深度マップにはshapeが`(1, 4)`の行列を使用する。
- 行列の行数・列数はともに4以下とする。

### 処理フロー目視チェックリスト

型、shape、値域、要素数および具体的な出力値は自動テストで検証し、このチェックリストには含めない。

- [ ] `initAIFImage(focalStack)`の呼び出しが処理フローから欠けていない。
- [ ] `initAIFImage`の戻り値を`initialAIFImage`として受け取っている。
- [ ] `initAIFImage`の完了後に`alternatingMinimization(initialAIFImage, focalStack)`を呼び出している。
- [ ] `alternatingMinimization`の戻り値を`depthMap`、`AIFImage`の順に受け取っている。
- [ ] 最後に`depthMap`、`AIFImage`の順で返している。
- [ ] 仕様書の処理フローに記載された処理が、途中で省略または別の処理に置き換えられていない。

### 不変条件

- 深度マップの全要素が0以上であることを確認する。
- AIF画像の全要素が0以上255以下であることを確認する。
- 本関数は画像上の座標およびカメラ座標を返さないため、座標範囲と基準カメラ原点の不変条件は本関数のテスト対象外とする。

### 型エラーテスト

- `null`に相当する`None`を入力した場合に`TypeError`が発生することを確認する。
- `FocalStack`以外の不適切な型を1種類入力し、`TypeError`が発生することを確認する。

### 数値条件エラーテスト

- 各ケースでは、対象の値だけを変更した`FocalStack`を`depthFromDefocus`へ直接入力する。
- テスト中に`initAIFImage`または`alternatingMinimization`をモックへ置き換えない。
- 画素値が0未満の場合に`ValueError`が発生することを確認する。
- 画素値が255を超える場合に`ValueError`が発生することを確認する。
- 焦点距離が0以下の場合に`ValueError`が発生することを確認する。
- 合焦距離に0以下の値が含まれる場合に`ValueError`が発生することを確認する。
- レンズ開口径が0以下の場合に`ValueError`が発生することを確認する。
- ピクセルサイズが0以下の場合に`ValueError`が発生することを確認する。
- 焦点スタックの画像枚数と合焦距離の要素数が一致しない場合に`ValueError`が発生することを確認する。
